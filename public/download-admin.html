Download the Admin app

Install the Admin page as its own app on Windows, iPhone or Android. It opens in its own window with the Admin icon and stays signed in. The rep tracker is a separate app.

360 Admin

One tap install where your browser supports it.

Windows PC

Microsoft Edge or Chrome

  1. Open this page in Edge or Chrome.
  2. Click Install now above, or the install icon at the right end of the address bar.
  3. Click Install. The app goes on your Start menu and desktop; right-click it to pin to the taskbar.
iPhone / iPad

Safari

  1. Open this page in Safari.
  2. Tap the Share button (square with an arrow).
  3. Tap Add to Home Screen, then Add.
Android

Chrome

  1. Open this page in Chrome.
  2. Tap Install now above, or the ⋮ menu → Install app.
  3. Tap Install. The icon lands on your home screen.
Send to a phone

Scan to open
